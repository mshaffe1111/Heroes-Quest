# Heroes Quest
Turn based strategy game where you conquer the world.

## Layout
- `engine/` the rules engine (no screen yet): maps, armies, combat, heroes, quests, computer players, stats ledger, doctrines. Run the tests with `cd engine && npm install && npm test`.
- `docs/` the army guide, and the site that GitHub Pages serves (`docs/index.html`).

## Branches
- `main` stable.
- `dev` work in progress.
