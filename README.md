# Heroes Quest
Turn based strategy game where you conquer the world.

Play page (test page for now): https://mshaffe1111.github.io/Heroes-Quest/

## What is here
- [`engine/`](engine) the rules engine (no screen yet): maps, armies, combat, heroes, quests, computer players, fog of war, doctrines, stats ledger, save and load, army orders. Source is in [`engine/src`](engine/src) and the tests in [`engine/test`](engine/test). Run them with `cd engine && npm install && npm test`.
- [`docs/`](docs) the [army guide](docs/Army_Guide.md) and the site that GitHub Pages serves.

## Branches
- `main` stable, always the latest finished work.
- `dev` work in progress.
