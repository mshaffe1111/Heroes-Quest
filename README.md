# Heroes Quest
Turn based strategy game where you conquer the world.

Play page (test page for now): https://mshaffe1111.github.io/Heroes-Quest/

## What is here
- [`engine/`](https://github.com/mshaffe1111/Heroes-Quest/tree/main/engine) the rules engine (no screen yet): maps, armies, combat, heroes, quests, computer players, fog of war, doctrines, stats ledger, save and load, army orders. Source is in [`engine/src`](https://github.com/mshaffe1111/Heroes-Quest/tree/main/engine/src) and the tests in [`engine/test`](https://github.com/mshaffe1111/Heroes-Quest/tree/main/engine/test). Run them with `cd engine && npm install && npm test`.
- [`docs/`](https://github.com/mshaffe1111/Heroes-Quest/tree/main/docs) the [army guide](https://github.com/mshaffe1111/Heroes-Quest/blob/main/docs/Army_Guide.md) and the site that GitHub Pages serves.

## Branches
- `main` stable, always the latest finished work.
- `dev` work in progress.
